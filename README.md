# Local AI Chatbot
 
A simple browser-based AI chatbot interface designed to work with locally hosted AI models through Ollama.
 
## Features
 
- Clean and lightweight web interface
- Connects directly to Ollama
- Works with local AI models
- No paid API required
- Fast local inference
- Privacy-friendly since all conversations stay on your machine
 
## Requirements
 
- Ollama installed
- A supported local AI model
 
Example:
 
```bash
ollama pull qwen2.5:1.5b
